# 多角度视图生成

同一张场景图补齐多个相机角度，供后续 3D 重建、资产拆分或多图参考使用。

## 适用范围

- 输入是一张已有的场景/房间图（2D 游戏截图或 3D 风格渲染图）
- 输出是**同一房间、同一套家具、同一画风**的另外几个视角
- 输出**不是**新设计、不是重排布局

## 通用约定

| 项 | 值 |
|---|---|
| 参考图 | 必须挂原场景图，权重最高 |
| 种子 | 所有视角用同一个种子 |
| 风格句 | 每个视角提示词末尾都要带同一段风格描述 |
| 禁止项 | 不要重排家具、不要增减物体、不要出现角色 / UI / 文字 / 水印 |
| 验收 | 逐件比对：物体数量、相对位置、关键细节（接口、标牌、发光条）是否与参考图一致 |

**风格句（每个视角都要带上）**

```
画风：2000 年代末中国科幻卡通，米白装甲板、深灰接缝与铆钉、青色发光条和玻璃，
平涂赛璐璐上色、干净的深色描边，柔和 PBR 光影。
```

## 视角清单

### ① 正视图（人眼高度，已完成并验证）

**用途**：唯一能给出高度信息的视角——墙有多高、天花板什么样、设备多厚。3D 重建必需。

**参数**：重绘幅度 0.5，比例 16:9，参考图权重最高。

```
把参考图的实验室场景改成从人眼高度拍摄的正面视角：相机位于房间南侧中央，离地约 1.7 米，
水平向北看，标准 50mm 焦距，无广角畸变、无俯视、无鱼眼。

保持完全相同的房间布局、每件家具的位置和朝向、配色和画风。画面中要清楚看到：
- 正对的三只孵化舱，以及它们背后的北墙、墙面面板接缝和墙脚青色灯带
- 天花板：中央网格灯板，以及灯板与四面墙交接的细节
- 左侧大型圆形控制设备的完整高度、厚度和侧剖面
- 右侧拱形门、罐装货架、红十字标牌
- 地面：深灰地板、青色导引线的走向、家具与地面的接触关系

不要重新设计，不要移动任何物体，不要增加或删除家具，不要出现角色、UI、文字和水印。
[风格句]
```

### ② 俯视正交平面图（待补）

用途：钉死相对位置和间距，拆分资产时最关键的一张。

### ③ 背面视图 / 反向视角（已完成，待验证）

**用途**：拿到各物件的背面结构——孵化舱的线缆接口、控制台的支撑、罐架的支架。这些是正视图永远看不到、而 3D 生成最缺的信息。

**参数**：重绘幅度 0.55–0.65，比例 16:9，参考图权重最高，**种子必须与正视图一致**。

```
把参考图的实验室场景改成从房间北侧向南看的反向视角——也就是正视图的背面：
相机位于北墙位置，离地约 1.7 米，水平向南看，标准 50mm 焦距，无广角畸变、无俯视。

保持完全相同的房间布局、家具位置、配色和画风。这个视角下应该看到：
- 前景是三只孵化舱的背面：米白装甲外壳、深灰接缝，下背部两根粗线缆接口和一个小散热格栅
- 左侧大型圆形控制设备的背面与侧后轮廓，能看到支撑结构和成束的线缆
- 右侧拱门的内侧，以及罐装货架的背面和支架结构
- 中央圆形传送台，从远处看过去，台面上方的悬浮水晶呈背光状态
- 南墙：参考图没有画过这一面，请按同一套设计语言补全——米白装甲板、深灰接缝、
  墙脚青色灯带连续延伸，中央可以有一扇关闭的舱门或观察窗，与北墙风格一致
- 地面：深灰地板、青色导引线连续延伸到南墙，家具与地面的接触关系清晰

不要改变原有家具的数量和位置，不要出现角色、UI、文字和水印。
保持同样的柔和环境照明，主光来自天花板灯板，青色灯带提供边缘光。
[风格句]
```

> 注意：背面视图里的南墙在原图中从未出现，只能由模型补全，**一旦定稿就成为该墙的唯一依据**，后续视角都要跟它对齐。这正是它必须和正视图用同一种子的原因。

## 常见坑

1. **重绘幅度低于 0.45 转不动视角**，会得到一张几乎没变的图；正视图 0.5、反向视角 0.55–0.65。
2. **三张图一起喂给下游模型时必须声明是同房间的三个视角**，否则会被当成三个不同场景。
3. **视角 A 和视角 B 不要用不同种子**，否则家具位置会对不上。
4. 出图后按"物体数量 → 相对位置 → 关键细节"三层顺序比对，不要只看画风像不像。
