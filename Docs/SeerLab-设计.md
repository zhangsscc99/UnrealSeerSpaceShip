## 5. 灯光方案（Lumen）

- **主光**：天花板网格灯板 → 区域光，冷白 6500K，强度中等
- **补光**：墙脚青色灯带自发光（不需要额外光源，靠 Lumen 反射）
- **视觉焦点**：传送台青色点光 + 水晶自发光，形成中央光柱
- **边缘光**：西侧控制设备青环、东侧门内溢光
- **后处理**：Bloom（阈值 1.0，强度 0.4）+ 轻微色差，不要开太重

## 8. 已知风险

- 原图俯视压缩 → 3D 会显空，靠增大层高和补充侧面细节补
- Meshy 输出三角面、无 UV、尺寸不统一 → 每件导入前必须统一缩放和朝向
- 卡通造型 + PBR 容易变成"塑料感" → 靠高粗糙度 + 接缝细节 + 不过度金属度来压住
